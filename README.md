# 매일 한 장 · 일본어 단어와 한자

한국어 UI의 Vanilla JavaScript 학습 앱입니다. 단어 750개(15일 × 50개), 한자 60자(10일 × 6자)를 포함합니다.

## 단어 학습

1. 일차를 선택하고 일본어 단어의 뜻을 떠올립니다.
2. 정답 확인을 누른 뒤 모른다 또는 알고 있다로 평가합니다.
3. 다음 카드로 자동 이동합니다. 이전 카드에서 평가를 수정할 수 있습니다.
4. 학습 완료 후 모르는 단어만 복습하기 또는 전체 다시 학습하기를 선택합니다.

오답 복습은 선택된 단어를 한 번씩 평가하면 끝납니다. 전체 다시 학습하기도 기존 숙련도 기록을 지우지 않습니다.

## 저장과 데이터

단어 숙련도는 일차와 원래 배열 위치를 식별자로 사용하며 jlpt_vocab_v2_ 이름공간에 저장합니다. 이전 버전의 유효한 기록을 이어받습니다. 기록은 일차의 표제어 목록(단어 또는 한자 순서)에 연결되므로 뜻·읽기·설명·암기법을 고쳐도 진행도가 유지되고, 표제어 자체를 바꾸거나 순서를 바꾼 일차만 새로 시작합니다. 일차 데이터 전체를 서명으로 저장하던 이전 형식의 기록도 표제어가 같으면 이어받으며, 다음 저장 때 짧은 서명으로 바뀝니다. 한자 학습 흐름과 저장 공간은 기존대로 유지합니다. 기록은 브라우저별로 저장되며 브라우저 데이터를 삭제하면 사라집니다.

wordData는 일차별 객체 또는 평탄한 배열을 지원합니다. 배열에 day가 없으면 원래 순서대로 50개씩 묶습니다. 원본 데이터는 변경하지 않습니다.

## 실행 및 검증

index.html을 브라우저로 열면 됩니다. 별도 프레임워크, 의존성, 빌드 단계는 없습니다.

```sh
node tests/check.cjs
node tests/exam-check.cjs
node tests/exam-data-check.cjs
```

정답 공개, 평가, 한 번만 이동, 재평가, 저장 복원, 복습 종료, 전체 재시작, 데이터 형식, 기록 마이그레이션을 검사합니다.
`exam-check.cjs`는 15개 전 DAY의 4지선다 모의시험 문제 생성, 채점, 답안 수정, 오답 추출, 오답 복습 카드 렌더링, LocalStorage 이력 보존을 검사합니다.
`exam-data-check.cjs`는 검수 문항 90개의 무결성과 선지 360개의 해설 보유·무작위 출제(한국어 혼입 0, 問題3 빈칸 （　） 정확히 1개, 4지선다, 중복 선택지·중복 단어 없음, 정답과 대상 단어 일치), 검증기의 결함 검출, 스크립트가 참조하는 모든 id의 HTML 존재 여부를 검사합니다.

## JLPT N3 어휘 모의시험 및 오답 복습

1. 홈 화면의 **JLPT 어휘 시험** 메뉴를 선택합니다. (메뉴 순서: 단어 공부하기 → JLPT 어휘 시험 → 한자 공부하기)
2. Day 1 ~ Day 15 카드에서 시험을 시작하고 풀이 방식을 고릅니다. 두 방식 모두 출제 가능한 문항 중 20문항을 Fisher-Yates 셔플로 무작위 출제하며, 선지 순서도 매번 섞입니다.
   - **한 문제씩 풀기**: 선지를 고르는 즉시 답이 확정되고 정답·해설이 바로 나옵니다. 답하기 전에는 다음 문제로 넘어갈 수 없고, 마지막 문제 뒤 결과 보기로 끝납니다.
   - **한 번에 풀기**: 이전/다음 이동과 답안 수정이 가능하며, 제출 시 미응답 문항은 오답으로 처리됩니다.
3. 실제 JLPT 시험 형식의 4지선다형 문제가 출제됩니다:
   - 유형 1: 한자 읽기 (漢字読み)
   - 유형 2: 한자 표기 (表記)
   - 유형 3: 문맥 규정 (文脈規定)
   - 유형 4: 유의 표현 (言い換え類義)
   - 유형 5: 용법 (用法)
   - Day 1~15마다 검수 문항 6개(문맥 규정 2 · 유의 표현 1 · 용법 1 · 한자 읽기/표기 2)가 항상 출제되고, 나머지는 단어 데이터로 자동 생성합니다.
   - 검수 문항은 `verifiedQuestions`에 `vq(wordId, type, prompt, [정답, 오답1, 오답2, 오답3], 용법 해설)` 형식으로 작성합니다. 問題5는 선지별 한국어 해설(notes)이 필수입니다. 출제 시 `validateVerifiedQuestion`을 통과한 문항만 사용합니다.
   - 밑줄 대상은 【 】로 표시하면 화면에서 밑줄로 렌더링됩니다.
4. 키보드: 1~4번 선택, 좌우 방향키 이동, 한 문제씩 모드에서는 Enter로 다음 문제.
5. **문항별 해설**: 결과 화면에서 모든 문항을 카드로 보여 줍니다(틀린 문항은 펼친 상태, 「틀린 문제만 보기」 필터 제공). 각 카드에는 정답을 채운 문맥 문장, 대상 단어의 표기·읽기·발음·뜻, 그리고 네 선지 각각의 표기·읽기·뜻이 나옵니다. 단어장에 없는 선지는 `EXAM_GLOSS` 해설 사전에서, 활용형은 기본형에서 찾고, 실제로 쓰지 않는 함정 읽기·표기는 함정이라고 표시합니다.
6. **오답 단어 복습**: 시험에서 틀린 단어만 자동 추출하여 기존 정답 카드 형식(단어, 히라가나, 발음, 뜻, 한자 구성, 설명, 암기법)으로 카드를 좌우로 넘기며 복습합니다.
7. 시험 이력은 `jlpt_exam_v1_DayN`에 누적 저장되어 Day 선택 화면에서도 이전 시험의 오답 복습으로 바로 진입할 수 있습니다.

## 오프라인(PWA)

- `manifest.webmanifest`(이름 「JLPT 어휘 시험」, `standalone`)로 홈 화면에 설치할 수 있습니다. 아이콘은 `icon-180.png`(iOS), `icon-192.png`, `icon-512.png`이며 같은 파일명으로 교체하면 됩니다.
- `service-worker.js`가 앱 파일(학습 데이터·CSS·JS가 모두 들어 있는 `index.html`, manifest, 아이콘)을 미리 캐시합니다. 온라인에서는 네트워크 우선으로 최신 배포를 받아 캐시를 갱신하고, 오프라인에서는 캐시로 응답합니다.
- 캐시할 파일 목록을 바꾸면 `CACHE` 이름의 버전 숫자를 올립니다. 서비스 워커는 HTTP(S)에서만 등록되며 `file://`로 열면 등록하지 않습니다.

## 배포

Vercel 프로젝트 `jlpt-n3-flashcards`는 이 GitHub 저장소와 **Git 연동이 활성화**되어 있습니다.

- `main` 브랜치에 푸시하면 운영(Production) 배포가 자동으로 실행됩니다: https://jlpt-n3-flashcards-three.vercel.app
- 다른 브랜치에 푸시하면 해당 브랜치의 Preview 배포가 자동으로 만들어집니다.
- 빌드 단계 없이 저장소 파일을 그대로 정적 배포합니다.

`main` 병합이 곧 운영 배포이므로, 테스트 3개를 통과시킨 뒤 승인을 받아 병합합니다.

## 일차별 학습 초기화

단어 또는 한자 목록에서 원하는 일차의 학습 초기화를 누릅니다. 확인 후 그 일차의 진행도와 숙련도만 처음 상태로 돌아갑니다. 다른 일차와 다른 모드의 기록은 유지합니다. 전체 다시 학습하기는 기존 숙련도를 보존하므로 초기화와 다릅니다.

## 읽기 전용 학습하기

단어 1–15일차의 학습하기 버튼으로 모든 정보를 바로 읽습니다. 좌우 스와이프, 이전/다음 버튼, 키보드 방향키로 이동하며 마지막 카드는 그대로 유지됩니다. 빈 보충 설명만 생략합니다.

읽던 위치는 jlpt_study_v1_DayN에 별도 저장합니다. 카드 열람은 퀴즈 진행도와 숙련도를 변경하지 않습니다. 기존 일차별 학습 초기화는 퀴즈 기록에 적용됩니다.

의존성 없이 공통 정보 렌더러와 기본 Pointer Events를 사용합니다. 모바일/데스크톱 브라우저 화면과 버튼·키보드·위치 복원을 확인했습니다. 스와이프 구분과 경계는 자동 테스트에 포함되며 실제 iPhone Safari 검증은 아직 하지 않았습니다.
