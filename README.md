# 매일 한 장 · 일본어 3급 단어장

[배포된 단어장 열기](https://jlpt-n3-flashcards-three.vercel.app/)

HTML, CSS, Vanilla JavaScript로 만든 한국어 플래시카드 앱입니다.

- 첫 회차는 순서대로, 이후에는 모르는 단어만 섞어서 반복합니다.
- 오답 풀이를 펼친 상태까지 브라우저에 저장합니다.
- 휴대폰 홈 화면 추가를 위한 아이콘과 웹 앱 매니페스트가 포함되어 있습니다.
- 현재 데이터는 샘플 단어 1개입니다. `index.html`의 `wordData`를 전체 JSON으로 교체하세요.

## 실행

`index.html`을 브라우저로 열면 됩니다. 홈 화면 설치는 HTTPS 배포 주소에서 이용하세요.

## 키보드

- 왼쪽 화살표: 모른다
- 오른쪽 화살표: 알고 있다
- 풀이 화면에서 스페이스 또는 엔터: 넘긴다

## 저장 안내

학습 기록은 기기와 브라우저별 localStorage에 저장됩니다. 브라우저 데이터 삭제 시 기록도 삭제됩니다. 서버 백업이나 기기 간 동기화는 제공하지 않습니다.

## 배포

Vercel의 `jlpt-n3-flashcards` 프로젝트에 정적 파일로 배포되었습니다. 빌드 명령과 외부 의존성은 없습니다. 이 저장소와 Vercel의 Git 자동 배포 연결은 별도 설정이 필요합니다.
