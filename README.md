# 매일 한 장 · 일본어 단어와 한자

[학습 앱 열기](https://jlpt-n3-flashcards-three.vercel.app/)

한국어 UI의 단어·한자 플래시카드 앱입니다. HTML, CSS, Vanilla JavaScript만 사용합니다.

- 홈에서 단어 또는 한자 모드를 선택합니다.
- 단어 15일, 한자 10일 과정이며 데이터가 없는 일차는 준비 중으로 표시합니다.
- 각 모드에 1일차 샘플 1개가 들어 있습니다. index.html 상단의 wordData와 kanjiData를 전체 데이터로 교체하세요.
- 첫 회차는 순서대로, 이후에는 모르는 항목만 섞어 반복합니다. 오답 풀이를 읽은 뒤 직접 넘겨야 다음으로 이동합니다.
- 모드별 저장 키(jlpt_vocab_Day1, jlpt_kanji_Day1)를 사용하며 기존 단어 기록도 이어받습니다.
- 왼쪽 화살표: 모른다 / 오른쪽 화살표: 알고 있다 / 풀이 화면에서 스페이스·엔터: 넘긴다.

## 실행과 설치

index.html을 브라우저로 열거나 위 배포 주소에 접속하세요. 휴대폰 홈 화면 추가를 위한 아이콘과 매니페스트가 포함되어 있습니다.

## 저장

학습 기록은 기기와 브라우저별로 저장됩니다. 브라우저 데이터 삭제 시 기록도 삭제됩니다. 기기 간 동기화나 서버 백업은 제공하지 않습니다.
